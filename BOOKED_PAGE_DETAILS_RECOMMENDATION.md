# BOOKED PAGE - ESSENTIAL DETAILS TO DISPLAY
## Recommendations for Information Hierarchy

---

## PRIMARY DETAILS (Always Visible)

These should be immediately visible on each booking card:

1. **Service Type** (with color coding) ⭐
   - Visual differentiation at a glance
   - Color-coded badge/label
   - Example: "COLOR", "HAIRCUT", "BLOWDRY"

2. **Model Name** ⭐
   - Primary identifier for the session
   - Example: "Seraphina Luna"

3. **Date with Day of Week** ⭐
   - Format: "Monday, December 15, 2024"
   - Helps with scheduling context

4. **Time Range (Start - End)** ⭐
   - Format: "2:00 PM - 5:00 PM"
   - Shows exact appointment window
   - Calculated from start time + duration

5. **Duration** ⭐
   - Format: "(180 min)" or "3 hours"
   - Quick reference for time needed

6. **Status Badge** ⭐
   - Confirmed, Completed, Cancelled, etc.
   - Color-coded for quick scanning

---

## SECONDARY DETAILS (Important but Collapsible/Expandable)

These should be accessible but can be in expandable sections:

7. **Location/Address** 🔷
   - Where the appointment takes place
   - Example: "Luxe Studio - 123 Main St, NYC"
   - Useful for navigation and confirmation

8. **Service Description** 🔷
   - Specific service details
   - Example: "Full color treatment with balayage highlights"
   - Helps understand what will be done

9. **Model Contact Information** 🔷
   - Email and Phone
   - For quick communication
   - Could be action buttons: "Email", "Call", "Message"

10. **Booking ID/Reference** 🔷
    - Example: "BK-2024-0015"
    - For support and record-keeping
    - Copy-to-clipboard functionality

11. **Model Fee/Payment** 🔷
    - Amount model receives
    - Payment status if applicable
    - Example: "Model Fee: $30"

12. **Professional Fee** 🔷
    - Your fee for the service
    - Total revenue

---

## TERTIARY DETAILS (On Demand / Modal/Detail View)

These can be in a detail view or modal when clicking the card:

13. **Model Profile Link** 🔸
    - Quick access to model's full profile
    - Photo, preferences, past work together

14. **Past Work Together** 🔸
    - History of previous sessions
    - Builds relationship context

15. **Model Preferences/Notes** 🔸
    - Hair preferences, allergies, special requests
    - Example: "Prefers warm tones", "Allergic to ammonia"

16. **Payment Details** 🔸
    - Payment method, transaction ID
    - Receipt link

17. **Cancellation Policy** 🔸
    - Terms, cut-off times
    - Rescheduling rules

18. **Quick Actions** 🔸
    - Message Model
    - Reschedule
    - Cancel
    - Add to Calendar (iCal/Google)
    - View Full Details

## ADDITIONAL RECOMMENDATIONS

### Visual Hierarchy:
1. **Service Type** - Largest, most prominent (color-coded badge)
2. **Model Name** - Second largest, bold
3. **Date/Time** - Medium size, clear formatting
4. **Details** - Smaller, but readable
5. **Actions** - Bottom, subtle but accessible

### Quick Actions Priority:
1. **Message** - Most common action (start conversation)
2. **View Profile** - Get context about model
3. **Reschedule** - Handle time changes
4. **Cancel** - Should be secondary/less prominent

### Calendar Integration:
- Show all bookings as colored dots on calendar
- Click date to filter/show bookings for that day
- Hover over dot to see service type
- Legend shows service type colors

### Mobile Considerations:
- Stack cards vertically
- Calendar below or in modal
- Collapsible detail sections
- Touch-friendly action buttons

## DETAILS THAT SHOULD BE "EASILY ON DISPLAY"

Based on professional workflow needs, here's what should be easily visible:

✅ **Immediately Visible (No clicking):**
- Service type (color-coded)
- Model name
- Date with day of week
- Start and end time
- Duration
- Status
- Location (one line)

✅ **Visible with Minimal Interaction:**
- Model contact info (click to call/email)
- Service description
- Booking ID (copy button)
- Model fee

✅ **Accessible but Not Cluttering:**
- Professional fee
- Payment status
- Model preferences/notes
- Past work history
- Full booking details
