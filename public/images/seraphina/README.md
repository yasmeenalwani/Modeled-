# Seraphina Luna's Portfolio Images

## How to Add Your Images

1. **Copy your PNG files** into this folder: `public/images/seraphina/`

2. **Name your files:**
   - `profile-headshot.png` - Main profile picture (this will show as the profile photo)
   - `photo-1.png` - First portfolio photo (side profile with blonde waves)
   - `photo-2.png` - Second portfolio photo (selfie with sunglasses)
   - `photo-3.png` - Third portfolio photo (close-up smile)
   - `photo-4.png` - Fourth portfolio photo (red lipstick, leather jacket)
   - `photo-5.png` - Fifth portfolio photo (headshot with necklaces)
   - `photo-6.png` - Sixth portfolio photo (pink top, gold necklaces)
   - `photo-7.png` - Seventh portfolio photo (salon selfie)

3. **That's it!** The images will automatically load in the app.

## Alternative: Use Different Names

If your files have different names, just tell me what they're called and I'll update the code to match!
