## Usage Notes for ML Training

1. **Image Preprocessing**: All images should be resized to consistent dimensions (e.g., 224x224 or 512x512) before training.

2. **Data Augmentation**: Apply rotation, flipping, brightness/contrast adjustments to increase training data variety.

3. **Multi-Label Classification**: Many images can have multiple tags (e.g., color level + undertone + treatment type).

4. **Confidence Thresholds**: Set appropriate confidence thresholds for each classification category.

5. **Validation Split**: Use 80/20 or 70/30 train/validation split for model evaluation.
