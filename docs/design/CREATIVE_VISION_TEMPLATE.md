## Example Usage

```
## Project Name
Cherry Desk - Financial Snapshot Section

## Visual Style & Mood
- Style: "Luxury magazine editorial with playful gold accents"
- Colors: "Cream background, cherry red (#8B1E3F) accents, gold (#D4AF37) highlights"
- Typography: "Bold serif numbers, elegant sans-serif labels"
- Vibe: "Feels like opening a high-end fashion magazine - sophisticated but inviting"

## Layout & Structure
1. **Financial Cards** (3-column grid)
   - Total Saved (large number, gold accent)
   - Sessions Completed (with mini chart icon)
   - Impact Contributed (with heart/badge icon)
   - Each card should have a subtle shadow and feel like a luxury card

2. **Monthly Progress Bar** (below cards)
   - Subtle gradient
   - Shows "This month: +$520"

## Content & Data Display
- Total Saved: $2,840 (large, bold, gold)
- Sessions: 34 (with upward trend icon)
- Impact: $47.25 (with heart icon)
- Monthly increase: +$520 (smaller, in cherry red)

## User Experience Goals
- Users should feel proud of their savings
- Should feel like they're achieving something valuable
- Numbers should feel tangible and rewarding

## Hair Photo References
- https://example.com/hair1.jpg (warm lighting, professional studio)
- https://example.com/hair2.jpg (luxury salon interior, gold accents)

## Special Requirements
- Custom hand-drawn border on cards (subtle, not heavy)
- Gold shimmer animation on hover (very subtle)
- Numbers should animate/count up on load

## Don't Want
- No neon colors
- No heavy gradients
- Keep it elegant, not flashy
```

## How to Use This Template

1. **Copy this template** into a new file in `docs/design/`

4. **Save and share** - I'll read it and implement!

## Tips for Best Results

✅ **Be specific** - "cherry red #8B1E3F" is better than "red"
✅ **Include images** - A picture is worth 1000 words
✅ **Describe feelings** - Tell me how it should FEEL, not just look
✅ **Use references** - Link to things you like
✅ **Set priorities** - What matters most?
